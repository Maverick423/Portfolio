Chocolate Chilli Game is a console-based Java game where two players take turns eating 1-3 chocolates from a pile. 
The player who takes the last chocolate wins, revealing a hidden chilli surprise! 
The game includes Easy, Medium (AI learns from memory), and Hard (perfect strategy) modes. 

Features include:
- Three difficulty levels
- Adaptive AI in Medium mode using memory from past games
- Keeping score across multiple rounds
- Input validation to ensure valid moves

To play: start the game, enter your name, choose a difficulty, select the number of starting chocolates (minimum 10) 
and total rounds, then take turns with the machine picking 1, 2, or 3 chocolates. 
The player who takes the last chocolate wins.

Built using Java standard libraries with file I/O for AI memory in Medium mode.
